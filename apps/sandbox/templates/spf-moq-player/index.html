MoQ Player

<simple-moq-video> inside the real <live-video-player> shell and skin — the MoQ engine driving actual Video.js controls. Defaults to a loopback relay: an in-page MSF publisher speaking draft-20 bytes over an in-memory transport, so playback works with no server. Point at a real relay with a full MSF URL (?relay=moqt://…%23msf:… — percent-encode the #, or the browser reads it as this page's fragment), or compose one from parts: relay host, broadcast path (what your token was issued for, e.g. mattypoo/room/42), and an optional JWT — the same ?relay=&ns=&token= params the publisher sandbox takes.
